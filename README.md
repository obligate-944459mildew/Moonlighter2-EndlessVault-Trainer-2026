## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Moonlighter 2: The Endless Vault**. This trainer provides optional quality-of-life and progression features for dungeon exploration, combat, loot management, shopkeeping, and town development.

**Target Audience:** Players who want to reduce grinding, experiment with weapons and perks, collect more relics, develop Tresna faster, or focus on the story and shop-management systems.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Move Will through dungeon rooms and village areas using the standard keyboard or controller controls. Use the dodge roll to avoid attacks, reposition during encounters, and navigate hazards. The trainer does not replace normal movement controls, so keep the game focused before using a hotkey.

### Tools & Inventory

Backpack space is central to every expedition. Arrange relics carefully because item placement can create useful interactions and synergies. Use capacity and quantity options before collecting or rearranging loot, then disable them before returning to the shop if you want to preserve normal progression behavior.

### World & Environment

Explore vibrant dimensions, defeat enemies, gather resources, and search for relics before returning to Tresna. Sell recovered items, reinvest profits in the shop and local establishments, and use upgrades to prepare for deeper runs and the escalating trials of the Endless Vault.

### Combat & Weapons

Combat combines light and heavy attacks, dodge rolls, weapon-specific fighting styles, armor sets, and powerful perks. Choose equipment that suits the current biome, learn enemy patterns, and use trainer options selectively when facing difficult encounters or bosses.
